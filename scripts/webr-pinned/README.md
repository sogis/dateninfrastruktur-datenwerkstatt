# webR-Paketspiegel für R 4.6

`PACKAGES` ist der gefilterte Paketindex des bereits verifizierten
V1-Spiegels. Die 40 Archive sind über Version und SHA-256 festgelegt.
Die Vorbereitung lädt die Archive direkt von ihren Versions-URLs.
Der Laufzeitspiegel liefert `PACKAGES` und `PACKAGES.gz`.

Das ursprüngliche `vroom_1.7.1.9000.tgz` liegt hier, weil r-wasm das
Archiv unter derselben URL und Version neu gebaut hat. Das archivierte
Original stammt aus dem lokalen V1-Spiegel und entspricht dem seit
`c1d4bc0` eingecheckten SHA-256. Die originalen Lizenzinformationen
stehen in `vroom/DESCRIPTION` und `vroom/LICENSE` im Archiv und
werden beim Build im Distributionsinventar mitgeführt.
